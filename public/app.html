Provider & privacy

OpenRouter · Whisper Large v3 (transcription) · Gemini 2.5 Flash (image and text analysis). This model pair must pass live readiness before every recording.

Audio, selected images, sanitized transcript, page context, and optional diagnostics go directly to OpenRouter and its model providers. Readiness sends bundled synthetic audio and an image and may incur a small API charge.

Detected text matches are removed locally. Audio and images are not automatically checked for secrets. Pattern checks cannot detect all sensitive information.

Requests debugger permission. No request bodies, headers, or form values. DevTools can interrupt diagnostics.

Tap and release quickly while the recorded page is focused. Narration also works without markers.

Tap timing & fallback shortcuts

100–350 ms · default 180 ms. Applies to both keys in the next recording. The second release triggers the marker immediately. A point freezes the pointer position and context at that moment.

Holding the key or combining it with another key cancels the gesture. Gestures need page access and do not work in the address bar. Alt+Shift+P / Alt+Shift+R remain available; configure them at chrome://extensions/shortcuts.

New tabs are excluded. After an origin change, restore page access to resume DOM context. Missing context is recorded explicitly.
